Cartzi
======

Overview
--------

Cartzi is a full-stack e-commerce web platform designed to provide a modern online shopping experience.

Purpose
-------

The project was built to deliver a modern, scalable e-commerce infrastructure with reliable backend API management, smooth state synchronization, and secure transaction workflows.

Technologies
------------

*   Next.js
    
*   React
    
*   Zustand
    
*   Sanity CMS
    
*   Stripe
    
*   Clerk
    
*   Node.js / Express
    
*   MongoDB / MySQL
    

Features
--------

*   Secure user authentication and profile management using Clerk.
    
*   Dynamic product content management managed through Sanity CMS.
    
*   End-to-end shopping cart state tracking managed by Zustand.
    
*   Secure payment gateway processing through Stripe.
    
*   Order tracking, customer management, and backend product inventory management.
    

Responsibilities
----------------

Ahmed handled the full-stack development, including backend database schema designs for products and orders, API endpoints for payment processing, frontend state management setup, and authentication flow integration.

Challenges
----------

Designing efficient database schemas for handling dynamic product attributes, orders, and reviews while ensuring stable, real-time checkout processing under API payment limits.

What this project demonstrates
------------------------------

Demonstrates expertise in full-stack e-commerce architecture, third-party payment integration, headless CMS management, and centralized client-side state management.
