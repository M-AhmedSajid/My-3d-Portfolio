Personal 3D Portfolio
=====================

Overview
--------

An interactive 3D portfolio website showcasing Ahmed's technical projects, skills, and resume details.

Purpose
-------

Built to deliver an engaging, visually distinct, and high-performance developer portfolio using modern 3D graphics and animations.

Technologies
------------

*   React
    
*   Next.js
    
*   Three.js
    
*   React Three Fiber
    
*   Framer Motion
    
*   Tailwind CSS
    
*   Firebase Hosting
    

Features
--------

*   Interactive 3D graphics rendered with Three.js and React Three Fiber.
    
*   Optimized routing and search engine visibility structured via Next.js.
    
*   Fluid UI animations designed using Framer Motion.
    
*   Fully responsive layout styled using Tailwind CSS.
    

Responsibilities
----------------

Ahmed designed, built, and deployed the portfolio application independently and open-sourced the repository on GitHub.

Results
-------

Successfully deployed on Firebase with optimized load times, proper accessibility, and smooth performance across screen sizes.

What this project demonstrates
------------------------------

Demonstrates proficiency in web 3D graphics rendering, complex layout animations, SEO optimization, and frontend application deployment.
