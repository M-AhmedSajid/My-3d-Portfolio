# Technical Skills

## Frontend Development

- **React & Next.js**: Ahmed uses React and Next.js to build modern, server-side rendered, and performant web applications with structured routing and optimal SEO capabilities.
- **HTML & CSS**: Foundation tools utilized to build accessible and structured interfaces.
- **Three.js & React Three Fiber**: Utilized to create interactive 3D web experiences and visual storytelling components.
- **Framer Motion**: Applied to introduce smooth UI animations and fluid interactive elements.

## Backend Development & APIs

- **Node.js & Express.js**: Used to build secure, scalable backend architectures, server-side logic, and RESTful APIs.
- **RESTful APIs**: Ahmed designs, documents, and consumes RESTful APIs to facilitate communication between client applications and backends.
- **Postman**: Employed for testing, debugging, and documenting backend API endpoints.

## Databases

- **MongoDB**: NoSQL database used for flexible schema design and managing document-oriented application data.
- **MySQL**: Relational database used for structured data storage, querying, and relational data handling.

## Styling & Component Libraries

- **Tailwind CSS**: Primary utility-first CSS framework used for building responsive, pixel-perfect user interfaces.
- **Bootstrap**: Used for structuring responsive design layouts and components.
- **shadcn/ui & Radix UI**: Accessible, customizable component primitives utilized for styling and layout structures.

## CMS & Content Management

- **Sanity CMS**: Integrated as a headless content management platform to enable client-managed dynamic content.

## Authentication & Payments

- **Clerk**: Implemented for seamless user authentication and session management.
- **JWT**: Used for secure token-based backend authentication.
- **Stripe**: Integrated to process secure payment flows and customer transaction workflows.

## State Management

- **Zustand**: Employed for client-side state management across complex web applications.

## Deployment, Version Control & Tools

- **Git**: Version control system used for tracking code changes and maintaining project codebases.
- **Firebase & Vercel**: Deployment and hosting platforms used to publish static, serverless, and dynamic web applications.
- **cPanel**: Managed for hosting environments and server deployments.
